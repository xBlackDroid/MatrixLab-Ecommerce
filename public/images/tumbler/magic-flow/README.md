# Fotografias de Magic Flow

Las fotos se vinculan por el handle estable del producto y se sirven desde:

```
public/images/tumbler/magic-flow/{codigo}.webp
```

Correspondencia:

```
mf001.webp  -> liquido-efecto-snowglobe  (Virgin Liquid Standard)
mf002.webp  -> mezcla-efecto-lava       (Virgin Liquid UV Pro)
mf003.webp  -> glicerina-movimiento-lento (Virgin Liquid Fast Dry)
```

Los productos administrados con una imagen propia en base conservan prioridad.
